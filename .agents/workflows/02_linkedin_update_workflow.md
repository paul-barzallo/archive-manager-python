# Workflow 02 — LinkedIn Technical Update

## Goal

Create a repeatable format for periodic posts about AI-assisted development and product AI evolution.

## Cadence

- Recommended: one post every 2 weeks.

## Structure

1. Problem solved in this iteration.
2. What AI automation improved in development workflow.
3. What changed in product/module behavior.
4. Evidence/metric (time, quality, reliability).
5. Next concrete milestone.

## Quality Gate

Only publish claims that are backed by implemented code or verified documentation.
