# Feature Delivery Workflow

## Goal

Deliver a feature or fix with controlled scope and architecture safety.

## Steps

1. Confirm request type:
   - If no explicit code request: analysis only.
   - If explicit code request: implementation mode.
2. Identify impacted module and layer boundaries.
3. Define acceptance criteria in short bullets.
4. Implement minimal viable change.
5. Validate with relevant tests/checks.
6. Update docs/changelog when required.
7. Prepare concise handoff with evidence.

## Exit Criteria

- Requested outcome is complete.
- No architecture boundary violations.
- Validation evidence is available.
